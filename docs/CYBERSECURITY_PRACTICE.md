# Cybersecurity Practice (Build 7)

**Defensive** job-prep only: identification, impact, prevention, detection, and incident response.

This build does **not** include malware, credential theft kits, phishing kits, exploit payloads, persistence/evasion tooling, or penetration-testing labs.
