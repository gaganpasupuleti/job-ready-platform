# Cloud Practice (Build 7)

Job-oriented cloud practice **without an AWS, Azure, or GCP account**. There are no cloud APIs, no live labs, and no certification exam dumps.

Label on tagged tracks: **Unofficial preparation. Not affiliated with any certification vendor.**

## Student routes

| Route | Content |
|-------|---------|
| `/cloud` | Tracks, continue, scenarios, paths, projects, weak topics |
| `/cloud/fundamentals` | Shared responsibility, IaaS/PaaS/SaaS, HA, elasticity |
| `/cloud/aws` | IAM, compute, storage, VPC, serverless, ops — job skills |
| `/cloud/azure` | Entra ID, VNets, storage, App Service, AKS concepts |
| `/cloud/gcp` | IAM, Compute Engine, Cloud Storage, GKE concepts |
| `/cloud/architecture` | HA, uploads, events, DR, scaling tradeoffs |
| `/cloud/security` | Identity, network controls, data protection |
| `/cloud/progress` | MCQ accuracy, scenario attempts, paths, projects |

MCQs use the **universal question engine** (domain `cloud`). Scenarios use the shared engine at `/scenarios/:slug`.

## What this build does not do

- No AWS/Azure/GCP credentials or SDK calls
- No Kubernetes cluster or Terraform Cloud
- No global job-readiness score

See [SCENARIO_ENGINE.md](SCENARIO_ENGINE.md).
