# DevOps Practice (Build 7)

Linux, Git, Docker, Kubernetes, CI/CD, Terraform, observability, and SRE **as concepts**. No live cluster, no remote shell execution, and no dangerous admin automation.

## Student routes

| Route | Content |
|-------|---------|
| `/devops` | Dashboard |
| `/devops/linux` | Filesystem, permissions, processes, logs |
| `/devops/git` | Branch, merge, rebase concepts, PRs |
| `/devops/docker` | Images, Compose, health checks, security |
| `/devops/kubernetes` | Pods, Deployments, Services — paper/cluster-free |
| `/devops/cicd` | Pipelines, artifacts, secrets, rollback |
| `/devops/terraform` | IaC, state, plan/apply — no live providers |
| `/devops/observability` | Metrics, logs, traces, SLOs |
| `/devops/sre` | Error budgets, incidents, toil |
| `/devops/progress` | Practice telemetry only |

MCQs: domain `devops`. Scenarios: `/scenarios/:slug` (troubleshooting, deployment, observability).

Projects such as **Dockerize a Web App** link Docker MCQs and a deployment-health scenario.
