# Indexing & Slicing

Indexing and slicing are techniques used to access, extract, or modify specific elements within a NumPy array. Indexing refers to selecting a single item based on its position, typically using square brackets and integer coordinates, while slicing allows you to retrieve a contiguous subset of the array by defining a range of indices using a colon separator. These methods provide a flexible way to work with parts of a dataset, such as selecting individual rows, specific columns, or smaller multi-dimensional segments without needing to iterate through the entire structure.
