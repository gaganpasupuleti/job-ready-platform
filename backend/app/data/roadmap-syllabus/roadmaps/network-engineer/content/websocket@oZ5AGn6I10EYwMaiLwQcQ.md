# WebSocket

WebSocket is a communication protocol that provides a persistent, full-duplex connection between a client and a server over a single TCP connection. Unlike traditional HTTP requests where the client must initiate every interaction, WebSockets allow for continuous, real-time data exchange in both directions once the initial handshake is complete. This makes it ideal for applications requiring low-latency updates, such as live dashboards, chat systems, and real-time gaming.
