# Reading for meaning in verbal ability

Verbal questions in placement papers usually test whether you can keep the meaning of a sentence without changing the facts. Start from the claim, then check each option against that claim.

## Learning objectives

- Identify the main claim in a short passage or sentence.
- Spot options that add facts the text never states.
- Prefer the option that preserves meaning with the fewest extra assumptions.

## Worked example

Sentence: “The team postponed the demo because the dataset was incomplete.”

Which restatement is closest?

- Correct idea: the demo moved later; the stated reason is an incomplete dataset.
- Wrong idea: the demo was cancelled forever.
- Wrong idea: the dataset was deleted.
- Wrong idea: the team finished early.

The word “postponed” keeps the event on the calendar. “Cancelled” removes it. “Incomplete” is not the same as “deleted”.

## Common mistakes

- Replacing a mild word with a stronger one (“postponed” → “cancelled”).
- Importing outside knowledge that the sentence never mentioned.
- Choosing an option that sounds fluent but flips the cause.

## Recap

Underline the claim, reject options that invent new facts, and keep the strength of the original wording. This lesson’s mark-as-read is reading progress only.
