# Number patterns in logical reasoning

Placement logical reasoning often asks for the next term in a sequence. The safe method is to write the difference or ratio between consecutive terms and check that one rule fits every step.

## Learning objectives

- Separate additive patterns from multiplicative patterns.
- Test a candidate rule against every consecutive pair.
- Reject a guess that only fits the first two terms.

## Worked example

Sequence: 2, 5, 11, 23, ?

Differences: 3, 6, 12. Each difference doubles. The next difference should be 24, so the next term is \(23 + 24 = 47\).

Another way to see the same rule: each term is “previous × 2 + 1”.

| Term | Rule | Value |
| --- | --- | --- |
| 1 | given | 2 |
| 2 | 2×2+1 | 5 |
| 3 | 5×2+1 | 11 |
| 4 | 11×2+1 | 23 |
| 5 | 23×2+1 | 47 |

## Common mistakes

- Fitting only the first jump and ignoring later terms.
- Mixing addition and multiplication without writing the check.
- Choosing the option that looks familiar instead of testing the rule.

## Recap

Write the rule, apply it to every known step, then predict the next term. Reading progress is not an assessed score.
